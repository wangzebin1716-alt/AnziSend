# AnziSend

AnziSend 是一款设备间文件传输工具。两台设备在可互访的局域网内时，无需互联网就能直传。身处不同网络时，可通过设备身份码尝试跨区域直连。Windows 版还能用本地 AI 分类整理收到的文件。

[官网下载](https://www.anzisend.cn/#download) · [打开网页版](https://api.anzisend.cn/connect) · [GitHub Releases](https://github.com/wangzebin1716-alt/AnziSend/releases)

## 选择连接方式

| 使用场景 | 怎么连接 | 需要满足的条件 |
| --- | --- | --- |
| 家里、办公室或校园内互传 | 在软件中查找接收设备，核对身份后发送 | 两台设备在内网中能够互访。即使连接不同 Wi‑Fi，或一台接网线，也可以直传。访客网络或设备隔离可能阻止互访。 |
| 不同城市或不同网络 | 用 12 位身份码查找对方，核对身份并添加好友，再尝试直连 | 双方在线并使用支持跨区域直连的版本，还需要可达的 IPv6 连接或成功的 IPv4 打洞。 |
| 通过浏览器收发 | 打开网页版，连接身份服务后查找设备或处理好友申请 | 浏览器会使用自己的设备身份码。选择已核对、在线的好友后，可以尝试收发文件。 |

跨区域直连属于测试功能。运营商 NAT、企业防火墙、VPN 或手机热点可能拦住直连。即使已搜到设备、已加好友，双方网络也可能无法建立传输连接。目前没有文件中继兜底。

## 收发、身份与整理

- **文件、文件夹与消息**。在软件中拖入文件或文件夹，查看接收确认和发送进度。桌面版提供接收目录设置、接收记录和大文件续传。
- **设备查找**。网页版首次连接、软件 build131 起首次创建身份查找资料时，默认允许按设备名称或身份码查找。已有设备的查找设置继续生效，你也可以关闭查找。
- **身份核对**。可核对设备证书指纹。Windows 聊天记录和草稿由当前系统账户加密保存。
- **Windows 本地 AI**。在本机分类整理收到的文件。轻量版按需下载模型，离线完整版在安装包中附带模型。

## 下载与反馈

公开测试包覆盖 Windows x64、Android ARM64 和 Linux x64。macOS、iOS 和 iPadOS 暂无可分发的安装包。下载后可用 Release 附带的 `SHA256SUMS.txt` 校验。

软件内的「反馈建议」可提交问题和改进建议。报告连接问题时，附上软件版本、双方网络类型、操作步骤和结果，有助于定位问题。
