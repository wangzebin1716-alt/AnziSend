# AnziSend

AnziSend 用于在电脑和移动设备之间发送文件和消息。身边互传优先走局域网，跨区域时可尝试互联网直连。Windows 还可在本机用 AI 整理收到的文件。

[官网与下载](https://www.anzisend.cn/) · [GitHub Releases](https://github.com/wangzebin1716-alt/AnziSend/releases) · [用户反馈](https://github.com/wangzebin1716-alt/AnziSend/issues/new/choose)

## 功能介绍

### 局域网文件互传

同一路由器下可自动发现设备，无需公网就能传文件。build129 已在两台 Windows 电脑上验证互相发现和 1 MB 文件往返，回传文件校验一致。

### 跨区域互联网直连（测试功能）

两端处在不同城市或不同网络时，可以通过身份码查找设备、确认身份，并尝试建立直连。两端需保持在线并启用互联网连接，且至少有一条路径可达，例如双方具备互通的公网 IPv6，或 IPv4 NAT 允许打洞。

### 哪些网络会连不上

如果双方没有可达的 IPv6，IPv4 打洞又被运营商 NAT、企业防火墙、VPN 或热点策略阻挡，传输就无法建立。查得到设备、已加好友或能连到协调服务，只说明信令可用。build129 的宽带与手机热点组合中，消息仍等待确认。目前线上没有文件中继兜底。

### 文件、文件夹与聊天

支持拖入文件或文件夹、发送文字消息、接收确认和传输进度。桌面版提供接收目录设置、大文件续传和接收记录。

### 设备身份与安全

使用 12 位身份码查找设备，可通过好友申请建立联系；连接时可核对设备证书指纹。Windows 聊天记录和草稿由当前系统账户加密保存。身份码和跨网能力依平台与版本提供。

### Windows 本地 AI

可在设备上为接收的文件分类整理。轻量版按需下载模型，完整版随安装包附带离线模型。

### 不同平台与网页版

公开下载页提供 Windows x64、Android ARM64 和 Linux x64 测试包，具体功能以版本为准。网页版提供浏览器连接入口。iOS／iPadOS 已有开发版本，尚未提供签名安装包。
